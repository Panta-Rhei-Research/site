{%- comment -%} AUD-12 · Chip row — split into two doctrine-distinct rows. Pre-v5: chips on result/prediction cards mixed layer identity (E0, E1, E2, E3, τ) with epistemic status (Prediction, Falsifiable, Canonical, Errata, …) in a single chip strip. The audit makes the case that these are semantically incompatible: layer chips answer "where in the program does this live?" while status chips answer "what is the epistemic standing of this claim?" — never the same question. v5 splits them into two non-mixing rows:
layer · E0/E1/E2/E3/τ
