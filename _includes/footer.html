{%- comment -%} AUD-19 · Inline footer search. Replaces the orphan "Search" heading-as-button (which had no input, just opened the overlay) with an actual text input — readers can type a query directly in the footer and submit, which opens the search overlay pre-populated with their query. Doctrine: "Inspectability begins with discoverability." Submit handler is defined inline so it works without JS module loading: writes the query into the Pagefind input inside #search-container, then calls openSearch() which is a global defined synchronously in default.html. Pagefind's debounced change listener picks the query up and renders results. {%- endcomment -%}
