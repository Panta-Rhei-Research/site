Hangs a uniform right-rail box on any page whose URL matches an entity in the research-graph manifest. The box lists the entity's persistent identifiers (DOI · ORCID(s) · OSF · GitHub · Wikidata) plus the entity's local prrp: id. Lookup is automatic — the include walks site.data.research_graph. entities once, picking the first entity whose `url` or `legacy_url` matches page.url. No per-page front-matter wiring is required; new artifacts get the box the moment they are added to the manifest. Render is skipped silently when no match is found (the rail just proceeds without the box), so the include is safe to call from any layout. Layouts that include this: publication-book (the Seven Books — current /publications/books/) publication-archive-book (first-edition archive) research-note (the eleven Research Notes) (research-paper layout is the standard page render with the paper landing pages — they use the same right-rail include and pick up the box automatically.)
