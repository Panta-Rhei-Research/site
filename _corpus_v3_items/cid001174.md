    \n```latex\nLet $\\varphi : \\Obj(\\tau) \\to \\Obj(\\tau)$ be an automorphism.\n\n\\medskip\n\\textbf{Step 1: $\\varphi$\
    \ fixes $\\omega$.}\n\nSince $\\omega$ is a named constant in the signature,\nany $\\Sigma_\\tau$-automorphism must fix\
    \ it:\n$\\varphi(\\omega) = \\omega$.\n\n\\medskip\n\\textbf{Step 2: $\\varphi$ fixes each generator.}\n\nSimilarly, $\\\
    varphi(\\alpha) = \\alpha$,\n$\\varphi(\\pi) = \\pi$,\n$\\varphi(\\gamma) = \\gamma$,\n$\\varphi(\\eta) = \\eta$.\nAll\
    \ five generators are fixed by $\\varphi$.\n\n\\medskip\n\\textbf{Step 3: $\\varphi$ fixes all orbit elements.}\n\nLet\
    \ $x \\in O_g$ for some $g \\in \\{\\alpha, \\pi, \\gamma, \\eta\\}$.\nThen $x = \\rho^n(g)$ for a unique $n \\geq 0$\n\
