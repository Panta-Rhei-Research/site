    # CRT Twin Admissibility


    ## Summary


    Twin-admissible residues mod M_k: r with neither r nor r+2 ≡ 0 (mod p_i) for all i≤k. Always nonempty.


    ## Statement


    ```latex

    \label{def:crt-twin-admissible}

    A residue $r \bmod M_k$ is \emph{twin-admissible} if for every

    prime $p_i$ ($i \le k$): $r \not\equiv 0 \pmod{p_i}$ and

    $r + 2 \not\equiv 0 \pmod{p_i}$.


    \textbf{Lean:} \texttt{crt\_twin\_admissible}.\quad

    \textbf{Registry:} III.D107.

    ```
