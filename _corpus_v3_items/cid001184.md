    # No Additive Inverse


    ## Summary


    For n > 0, no m in tau-Idx satisfies n + m = 0. The absence of additive inverses is structural: rho generates positive
    depths only.


    ## Statement


    ```latex

    %

    \label{thm:no-additive-inverse}

    For any $\underline{n} > \underline{0}$ in $\tau$-Idx,

    there exists no $\underline{m} \in \tau$-Idx such that

    $\underline{n} + \underline{m} = \underline{0}$.

    ```


    ## Proof / Justification


    ```latex

    Immediate from Proposition~\ref{prop:sum-zero-iff}:

    if $\underline{n} + \underline{m} = \underline{0}$,

    then $\underline{n} = \underline{0}$,

    contradicting $\underline{n} > \underline{0}$.

    ```
