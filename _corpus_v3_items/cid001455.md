    # Gap Type


    ## Summary


    Three gap types: parity (Goldbach), density (twin primes), structural (ABC). Complete taxonomy of proof-theoretic gaps.


    ## Statement


    ```latex

    \label{def:gap-type}

    The three proof-theoretic gaps:

    \begin{enumerate}

    \item \textbf{Parity gap} (Goldbach): the parity barrier blocks any

    sieve-based approach from proving Goldbach for all~$n$.

    \item \textbf{Density gap} (Twin primes): admissible residue classes are

    nonempty (algebraic), but infinitude requires equidistribution (analytic).

    \item \textbf{Structural gap} (ABC): the primorial tower avoids the hard

    case entirely; genuine difficulty is in perfect-power parts.

    \end{enumerate}


    \textbf{Lean:} \texttt{GapType} in \texttt{ConjectureGaps.lean}.\quad

    \textbf{Registry:} III.D112.

    ```
