    # Sieve-CRT Compatibility


    ## Summary


    Sieve-CRT compatibility: n divisible by p_i iff i-th CRT residue is 0. Multiplicative sieve = product of local sieves.


    ## Statement


    ```latex

    \label{prop:sieve-crt}

    An integer~$n$ is divisible by some $p_i$ ($i \le k$) if and only if

    the CRT decomposition $(n \bmod p_1, \ldots, n \bmod p_k)$ has a zero

    component.  The multiplicative sieve equals the product of local sieves

    via CRT.


    \textbf{Lean:} \texttt{sieve\_crt\_compat\_3}.\quad

    \textbf{Registry:} III.P42.

    ```
