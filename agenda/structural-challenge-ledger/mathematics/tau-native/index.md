## τ-native mathematical challenge families

These are not new content. They are existing τ pages surfaced as challenges so the structural challenge ledger makes the framework's internal commitments visible.

| Family | Challenge |
|---|---|
| **T1 — Kernel Categoricity and Rigidity** | Can the five-generator / one-operator / seven-axiom kernel be characterized uniquely enough to support the later construction? |
| **T2 — Central Theorem Bridge** | Can the central theorem be stated, checked, and bridged so external mathematicians can inspect it without assuming τ semantics? |
| **T3 — τ-Zeta and Spectral Arithmetic Bridge** | Does τ-zeta connect to classical zeta/L-function structures, or only to an internally analogous spectral object? |
| **T4 — GRH / Grand-GRH Hierarchy** | See [CB-GRAND-GRH](/agenda/structural-challenge-ledger/mathematics/canonical-benchmarks/grand-grh-spectral-arithmetic-hierarchy/). |
| **T5 — τ-Topos and Internal Logic** | What topos-like or internal-logic structure is earned, and how does it compare to ordinary topos theory? |
| **T6 — Address Resolution and Hyperfactorisation** | Can address-level construction produce standard arithmetic, factorisation, and complexity constraints? |
| **T7 — Diagonal Limitation / Gödel-Cantor-Tarski Pressure** | See [F5 — Gödel Limitation](/agenda/structural-challenge-ledger/mathematics/foundations-logic/godel-limitation/). |
| **T8 — Formalization Adequacy** | See [F16 — Computability and Formalisation](/agenda/structural-challenge-ledger/mathematics/foundations-logic/computability-formalization/). |
