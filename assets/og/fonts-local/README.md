# Local OG Production Fonts

These fonts are used only by the deterministic OG/Twitter card generator.
They are vendored so preview cards can be rebuilt without external font
requests.

Included open-source font files:

- `EBGaramond-Regular.ttf`
- `SourceSans3-Regular.ttf`
- `SourceCodePro-Regular.ttf`
- `MaterialSymbolsRounded-Regular.ttf`

Do not add proprietary font files to this directory.
